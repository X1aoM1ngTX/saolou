# 扫楼打分本 · 城中村看房实时评分对比

一个纯前端的单文件网页工具，用于佛山城中村扫楼看房时现场打分、横向对比。

**在线使用：<http://saolou.1000ye.top/>**

手机浏览器打开 → 添加到主屏幕，即可像 App 一样使用。数据全部保存在本机浏览器，不上传任何服务器。

---

## 它解决什么问题

一天跑十几套城中村房源时，纸质记录的问题是：看完十套后照片、租金、水电费全混在一起，没法横向比较；二房东加价、暗间、顶楼西晒这些坑也容易漏问。

这个工具让你**边问房东边填**，分数实时计算、自动排名，看完就能决定复看哪套。

## 功能

**评分模型（满分 100，权重可调）**

| 项目 | 默认权重 | 规则 |
|---|---|---|
| 租金 | 25 | 450 元内满分，越贵越低 |
| 通勤 | 10 | 按方式折算：骑车 10 分钟 / 步行·电动车 15 / 开车 20 / 公交地铁 30 分钟内满分 |
| 水电合理度 | 10 | 民用电 0.59–0.65 元/度满分，1.2 元以上近乎 0 分 |
| 硬件齐全度 | 25 | 19 项硬件勾选占比 |
| 主观印象 | 30 | 4 项各 1–5 分 |

风险项自动扣分：二房东 / 暗间各 −8，顶楼 / 一楼各 −5，电费超 1.2 再 −6。
权重可在「评分设置」里调整，改动后自动按比例折算为合计 100，并内置「租金优先 / 通勤优先 / 省心优先」等预设。

**其他能力**

- **自定义房名**：列表点房名直接改名；留空则默认显示「村名＋门牌号」
- **现场照片**：每套 1–9 张，压缩后存 IndexedDB（不挤占 localStorage），列表缩略图 + 全屏灯箱
- **地图分布**：接高德地图 JS API，房子与公司一起打点，按排名编号
- **导航路线**：点房子标记即画出到公司的导航轨迹（按通勤方式切换步行/骑行/公交/驾车），可一键用路线时间修正通勤时长
- **状态标记**：候选 / 已约复看 / 已定 / 淘汰，顶部按状态筛选并统计
- **首月支出**：押金＋首月租金＋中介费，一眼看清入住要掏多少钱
- **备份恢复**：导出 JSON（含照片），换手机或清缓存后可完整恢复
- **示例数据**：首次访问自带 4 套不同等级的示例，打开就懂怎么用

## 技术说明

单文件 `index.html`，无构建、无依赖、无后端。

- 记录与设置存 `localStorage`（key `fs-rent-scorer-v1`）
- 照片存 `IndexedDB`（库 `fs-rent-scorer-pics`），压缩至最长边 1600px、JPEG 质量 0.75
- 地图使用高德 JS API 2.0（需在控制台为该 key 配置域名白名单）
- 界面为 GitHub / Primer 风格，系统字体栈，无外部字体请求

## 部署

把 `index.html` 和 `saolou.svg` 放到任意静态站点根目录即可，无需服务器逻辑。

```bash
# 本地预览
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

> 注意：直接双击打开 `file://` 也能用大部分功能，但地图和定位建议通过 http/https 访问。

## 已知限制

- 数据只存在当前设备的浏览器里，换设备需用「导出备份 / 从备份恢复」
- 地图需联网加载；断网时地图不可用，但不影响打分和记录
- 「用当前位置」定位需要 HTTPS，HTTP 站点下只能点地图打点
